# Text-to-SQL API 模型最终实验报告

本文基于统一的测试集、统一的提示词格式和统一的阿里百炼 API 调用方式，对多个原始大语言模型的 Text-to-SQL 生成能力进行了横向对比。评价指标包括 JSON 格式正确率、ROUGE-1、ROUGE-L 和 BLEU，并分别从总体、双表和三表三个层面进行统计。

## 一、关键结论

- 总体表现上，`MiniMax-M2.5` 的 ROUGE-1 最高，为 75.18；`MiniMax-M2.5` 的 BLEU 最高，为 50.64。
- 在输出格式约束方面，`deepseek-v4-flash` 的 JSON 格式正确率最高，为 100.00%。
- 双表场景中，ROUGE-1 最优模型为 `MiniMax-M2.5`，得分为 73.17。
- 三表场景中，ROUGE-1 最优模型为 `MiniMax-M2.5`，得分为 81.84。
- 从双表到三表的 ROUGE-1 变化看，`MiniMax-M2.5` 提升最明显（+8.68），而 `glm-5` 变化最弱（-3.93）。

- 总体结果：JSON格式正确率 100.00%，ROUGE-1 75.18，ROUGE-L 68.73，BLEU 50.64。
